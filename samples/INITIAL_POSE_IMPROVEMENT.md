# 初期姿勢改善 - 後ろに倒れる問題を解決

## 🔍 問題の原因分析

ロボットが初期姿勢のまま**後ろに倒れてしまう**理由は3つありました：

### 1. **膝の角度が大きすぎた**

```python
# ❌ 以前の設定
膝角度 (J3) = 0.8 rad  (≈ 45.8°)
Hip Pitch (J1) = 0.0 rad  (垂直)
```

**問題**: 膝が大きく曲がると、重心が足首より後ろに移動してしまい、後ろに倒れやすくなります。

```
膝 0.8 rad の場合:
     CoM (重心)
       ↓
    [上半身]
    ////////zzz ← 重心が足の後ろ → 後ろに倒れる！
```

### 2. **Hip Pitch がニュートラルだった**

```python
# ❌ 以前
Hip Pitch (J1) = 0.0 rad  (完全垂直)
```

正しい二足歩行は、重心を足の上（支持足）に保つために、**軽く前傾**する必要があります。

### 3. **セトリング期間が短すぎた、または無効だった**

```python
# ❌ 以前
for step in range(50):
    self.robot.set_dofs_position(...)
    self.scene.step()

# セトリングはコメントアウト（無効）
```

## ✅ 修正内容

### 修正1: 初期姿勢を標準的な立ち姿勢に変更

```python
# ✅ 修正後
initial_angles = np.array([
    # 左脚
    0.0, -0.1, 0.0, 0.25, -0.15, 0.0,
    #    J0   J1   J2    J3     J4     J5
    #    Roll Pitch Yaw  Knee  Ankle  Roll
    #                         ↑ 0.25 rad (≈ 14.3°: 軽く曲がった自然な状態)
    #           ↑ -0.1 rad (≈ -5.7°: 軽く前傾)
    
    # 右脚: 同じ
    0.0, -0.1, 0.0, 0.25, -0.15, 0.0,
    # ...
], dtype=np.float32)
```

**パラメータの意味**:
- `J0 (Roll)`: 0.0 → サイドロール なし
- `J1 (Hip Pitch)`: -0.1 rad → **軽く前傾** (重心を足の前に移動)
- `J2 (Yaw)`: 0.0 → 回転 なし
- `J3 (Knee)`: 0.25 rad → **軽く曲がった自然な状態** (歩行可能)
- `J4 (Ankle Pitch)`: -0.15 rad → 足首を立たせ続ける
- `J5 (Ankle Roll)`: 0.0 → サイドロール なし

```
修正後の立ち姿勢:
     CoM (重心)
       ↓
    [上半身] ← 軽く前傾 (-0.1 rad)
    \\\\\\\\\\
    =========== (支持足)
    ↑重心がしっかり足の上にある → 安定！
```

### 修正2: ダンピングゲイン（kv）を大幅に増加

```python
# ❌ 以前
kv (脚) = 20.0
kv (腰) = 15.0

# ✅ 修正後
kv (脚) = 30.0  ← 1.5倍に増加
kv (腰) = 25.0  ← 1.7倍に増加
kv (腕) = 15.0  ← 1.5倍に増加
```

**効果**: ダンピングが強くなると、振動が素早く減衰して、安定した状態を保持します。

### 修正3: セトリング期間を大幅に延長

```python
# ❌ 以前
for step in range(50):
    self.robot.set_dofs_position(initial_angles, ...)
    self.scene.step()
# セトリングは無効

# ✅ 修正後
# ハードリセット: 100ステップ
for step in range(100):
    self.robot.set_dofs_position(initial_angles, self.dofs_idx_local)
    self.scene.step()

# セトリング: 300ステップ ← 大幅に延長
for settle_step in range(300):
    self.robot.control_dofs_position(initial_angles, self.dofs_idx_local)
    self.scene.step()
    if settle_step % 100 == 0:
        print(f"  Settling: {settle_step}/300 steps")
```

**時間にして** (dt=0.02s の場合):
- ハードリセット: 100 × 0.02 = **2秒**
- セトリング: 300 × 0.02 = **6秒**
- **合計: 8秒で完全に安定した状態に**

### 修正4: スポーン高さを調整

```python
# ❌ 以前
pos=(0.0, 0.0, 0.75)

# ✅ 修正後
pos=(0.0, 0.0, 0.85)  ← 10cm 高める
```

**理由**: より高い位置からスタートすることで、膝の角度を効果的にでき、より自然な立ち姿勢に収束しやすくなります。

## 💡 技術背景

### 重心と支持足の関係

二足歩行ロボットが安定立位にあるための必要条件：

```
支持多角形 (Support Polygon):
┌────────────────────────────┐
│         両脚が接地          │
│      ┌──────────┐          │
│      │  重心    │          │
│      │   (CoM)  │          │
│      └──────────┘          │
│  ←── 重心がこの範囲内 ──→  │
└────────────────────────────┘
```

**重心が支持多角形の外 → 倒れる**
**重心が支持多角形の中央 → 安定**

### PD制御とダンピング

```
制御力 τ = kp × (θ_target - θ) + kv × (ω_target - ω)
           ↑ 位置制御           ↑ ダンピング
```

- `kp` が大きい → 目標位置に強く追従 (ただし振動しやすい)
- `kv` が大きい → 速度を抑制 (振動を減衰)

**低い kv**: 振動が継続 → 倒れやすい
**高い kv**: 振動が減衰 → 安定しやすい
